这是一道经典的接口规范与多态的工程题目。在大型后端系统中（如电商），我们经常需要对接多种支付渠道（支付宝、微信、银联），利用 ABC 和 @abstractmethod 强制定义统一的标准是非常必要的。

题目：通用支付网关系统 (Payment Gateway System)
背景描述： 你正在开发一个聚合支付系统。为了保证所有第三方支付渠道（如支付宝、微信）都遵循统一的调用规范，你需要定义一个抽象基类。

需求规范：

引入 Python 的 abc 模块。

定义一个抽象基类 PaymentGateway，继承自 ABC。

在基类中定义两个抽象方法（使用 @abstractmethod 装饰）：

pay(self, amount): 处理支付。

refund(self, order_id): 处理退款。

实现两个具体的子类：

AliPay (支付宝)：

pay: 打印 "支付宝支付: [amount]元"，并返回 True。

refund: 打印 "支付宝退款: 订单号 [order_id]"。

CreditCard (信用卡)：

pay: 信用卡支付需要收取 1% 的手续费。打印 "信用卡支付: [amount + 手续费]元 (含1%手续费)"，并返回 True。

refund: 打印 "信用卡退款: 订单号 [order_id]"。
